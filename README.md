# 陽原 瑛樹 ポートフォリオ

農業 × IT / 業務改善をテーマにしたシングルページのポートフォリオです。

## ローカルでの確認

`index.html` をブラウザで開いてください。VS Code の Live Server などでも確認できます。ビルドコマンドは不要です。

## 公開前の必須設定

1. `js/main.js` 冒頭の `CONTACT_EMAIL = ''` に公開用メールアドレスを設定してください。未設定の間はContactボタンを無効にしています。
2. `index.html` の文章、在籍期間、成果数値などを最終確認してください。
3. 実機でPC・スマートフォン表示、メニュー操作、実績詳細の展開、メールリンクを確認してください。
4. 公開先が決まったらcanonical URL、OGP画像などの公開用メタデータを追加してください。

## 構成

- `index.html`: セマンティックなHTMLと掲載内容
- `css/style.css`: デザイントークン、レイアウト、レスポンシブ、モーション
- `js/main.js`: モバイルメニュー、メールリンク、スクロール演出
- `assets/`: 今後の画像・アイコン用（現時点では画像なし）

## 留意事項

- 外部フォントの読み込みができない環境ではシステムフォントにフォールバックします。
- JavaScriptが無効でも本文と実績の詳細を閲覧できます。メールリンクはアドレス設定後にJavaScriptで有効になります。
- フレームワーク、ビルドツール、CMSは使用していません。
